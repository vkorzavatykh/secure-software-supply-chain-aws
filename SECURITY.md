# Security Policy

This repository is a personal proof of concept, not a maintained product. There is no permanently running
environment, so there are no live systems to test against.

If you find a security problem in the code, the Terraform or the pipeline (for example a permission that
is broader than documented, or a way to bypass the security gate), please report it privately through
GitHub's [private vulnerability reporting](https://github.com/vkorzavatykh/secure-software-supply-chain-aws/security/advisories/new)
rather than in a public issue.

The intended security model is documented in [docs/security.md](docs/security.md).
